# «Сөздер лабиринті: қазақ тілінен интерактивті ойын құрастыру»

«Зерде» конкурсы (2026–2027) · Қоғамдық-гуманитарлық бағыт · «Қазақ тілі және әдебиеті» секциясы · «Бастауыш буын» (3-сынып) · цифрлық жоба, жеке жоба.

## Ойын

- Интернетсіз ойнау үшін `oiyn/index.html` файлын кез келген браузерде ашыңыз.
- Интернет арқылы ойнау үшін: https://claude.ai/artifact/NWRfvmZBJcKwFvs5nTSzuU. Сілтеме әзірге жеке (private). Басқалар ашуы үшін (стендтегі QR-код та осыған апарады) бетті ашып, **Share** мәзірінен сілтемені ашық қылыңыз.
- Ойында 5 деңгей, 65 қақпа сұрағы, ойынға дейін және кейін тапсырылатын 10 сұрақтық тест, 3 сұрақтық сауалнама бар. «Нәтижелер» беті деректерді жинайды, оларды Excel-ге көшіруге болады.

## Міндетті түрде өзіңіз орындайтындарыңыз

1. **Сары түспен белгіленген барлық жерді** толтырыңыз: аты-жөндер, күндер, сынақ нәтижелері, рефлексия.
2. **Сынақты шынымен өткізіңіз.** Ата-ана келісімін алыңыз (Г қосымшасы). Содан кейін тест → ойын → тест → сауалнама. Жұмыстағы нәтижелерді ойынның «Нәтижелер» бетінен алыңыз. Деректерді ойдан шығаруға болмайды (2.16, 4.10-тармақтар).
3. **Мәтінді оқушы өз сөзімен қайта жазсын.** Жұмыс мәтіні мен құжаттардың үлгісін ЖИ дайындады. 4.10-тармақ ЖИ жасаған дайын мәтінді ұсынуға тыйым салады, ал 3.3-тармақ бойынша ЖИ оқушының өз еңбегін алмастырмауы керек. ЖИ декларациясы да шындыққа сай болуы тиіс.
4. **Антиплагиатты нақты сервисте тексеріңіз.** Пайызы мен күнін анықтамаға сол тексеруден кейін ғана жазыңыз.
5. Сұрақтарды мұғаліммен және оқулықпен тексеріңіз. Дереккөздер тізіміндегі 1 және 6-тармақтарды мектептегі нұсқа бойынша нақтылаңыз.

## Қайта құрастыру

```bash
cd source && npm install && pip install pypdf "qrcode[pil]" openpyxl
./build.sh          # DOCX → PDF (LibreOffice керек), мазмұнындағы беттер өздігінен анықталады
node shots.js       # ойын скриншоттары (Playwright)
node stend.js       # стенд панельдері
python3 xlsx.py     # Excel кестесі
python3 qr.py <URL> # сілтеме өзгерсе, QR-кодты қайта жасау
```

# «Қазақ ертегілеріндегі сандар құпиясы» – «Зерде» зерттеу жобасы

Секция: Қазақ тілі және әдебиеті (ҚГБ), «Орта буын», 7-сынып, жеке жоба.

## Файлдар

| Файл | Не үшін |
|---|---|
| `Zertteu_zhumysy.docx / .pdf` | Зерттеу жұмысы (ұйымдастырушыға арналған дана) |
| `Zertteu_zhumysy_qazylar_danasy.docx / .pdf` | Қазылар данасы – аты-жөнсіз, тек шифр |
| `Zertteu_kestesi.xlsx` | Оқушы толтыратын кесте: ертегілер, сандар; «Қорытынды» өздігінен есептеледі |
| `Zertteu_kundeligi.docx` | Зерттеу күнделігі (6-қосымша) |
| `ZhI_deklaratsiyasy.docx` | ЖИ пайдалану туралы декларация (4-қосымша) |
| `Etika_paragy.docx` | Этика және қауіпсіздік бақылау парағы (5-қосымша) |
| `Zhetekshi_pikiri.docx` | Жетекші пікірі |

## Оқушы не істейді

1. 14 ертегіні оқып, кездескен әр санды `Zertteu_kestesi.xlsx` → «Сандар» парағына жазады: ертегі, сан (цифрмен), мәтіндегі тіркес, нені білдіреді, қызметі (Н – нақты, Ф – формула/символ), беті.
2. «Ертегілер» парағында кітапты, оқылғанын және үштік құрылымды (үш ағайынды, үш сынақ) белгілейді.
3. Толтырылған кестені жібереді – кестелер, диаграммалар, аннотация мен қорытынды өздігінен толады, содан кейін талдау мәтіні нақты деректерге сай жазылады.

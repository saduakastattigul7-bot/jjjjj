# Қайнау сабағын бағалау — онлайн нұсқа

Бұл «Қайнау сабағын бағалау» қосымшасының бірнеше ноутбукте бір уақытта жұмыс істейтін нұсқасы. Сабақта 4 топ 4 бөлек ноутбукпен жұмыс істейді. Мұғалімнің бесінші құрылғысында барлық топтың деректері бір кестеге жиналып, бетті жаңартпай жаңарып тұрады.

Дизайн, қазақша мәтіндер, тапсырмалар, дескрипторлар, топ атаулары және бағалау формуласы (жалпы балл / 23 × 10) бастапқы нұсқадағыдай қалды. Бастапқы бір файлдық нұсқа `claude/eager-sagan-8jisgj` тармағында, `fizika-qainau/index.html` файлында тұр.

| Файл | Не үшін |
|---|---|
| `public/index.html` | Қосымшаның өзі (мұғалім режимі + топ режимі) |
| `public/firebase-config.js` | Firebase жобасының веб-баптаулары. Оларды **сіз толтырасыз** |
| `firestore.rules` | Дерекқордағы қолжетімділік ережелері (сервер жағында тексеріледі) |
| `firebase.json` | Firebase Hosting пен ережелерді жариялау баптауы |
| `tests/` | Ережелер тесті және 5 браузерлік толық тест (эмуляторда) |

---

## 1. Қалай жұмыс істейді

**Бастапқы бет:** екі батырма бар, **МҰҒАЛІМ** және **ТОП**.

**Мұғалім:**
1. Email мен құпия сөз арқылы кіреді (Firebase Authentication).
2. **«Жаңа сабақ отырысын ашу»** батырмасын басады. 6 таңбалы сабақ коды, сілтеме және QR код жасалады.
3. **«Бақылау»** бетінде мыналар көрінеді:
   * әр топтың күйі: **Қосылған / Байланыс үзілді / Қосылмаған**, **Соңғы жаңарту** уақыты және аяқталған кезеңдер;
   * барлық оқушының кестесі. Бағандары: топ, аты-жөні, үй тапсырмасы 0–3, эксперименттен кейін 0–2, топтық жұмыс 0–9, жеке жұмыс 0–9, жалпы 0–23 және 10 балдық баға;
   * сыныптың орташа балы, үздік 5 нәтиже, CSV жүктеу, басып шығару / PDF.
4. **«Түзету»** батырмасы арқылы кез келген дескрипторды немесе топтық жұмыстың жауабын түзетеді. Түзетілген балл ✎ белгісімен көрінеді, ал оқушылар оны өзгерте алмайды. Оқушылардың өз белгілері өзін-өзі бағалау ретінде бөлек сақталады.
5. **«Тәжірибе»** бетінде төрт топтың температура кестесі, графигі және талдау жауаптары көрінеді.
6. **«Сынып нәтижесі»** бетінде бастапқы нұсқадағы қорытынды тұр: оқу картасы, жеке кері байланыс және топтық жұмыс талдауы.
7. **«Сабақты аяқтау»**: осыдан кейін топтар деректі өзгерте алмайды. Мұғалім түзетуді жалғастыра алады.

**Топ:**
1. Сілтемені немесе QR кодты ашады. **ТОП** батырмасын басып, кодты енгізеді (сілтемеден өзі толады) және өз тобын таңдайды:
   1-топ — АЛЬПИНИСТЕР, 2-топ — РЕСТОРАТОРЛАР, 3-топ — ИНЖЕНЕРЛЕР, 4-топ — ЗЕРТТЕУШІЛЕР.
2. Оқушылардың аты-жөнін жазады. Содан кейін 1–4 кезеңдерді бастапқы нұсқадағыдай белгілейді.
3. Зертханалық жұмыста кесте, график және жауаптар тек осы топтың деректеріне сақталады. «Графикті тазалау» басқа топқа тимейді.
4. Жоғарыда сақталу күйі көрсетіледі: **Сақталуда…** → **Сақталды**, интернет үзілсе **Байланыс жоқ**. «Сақталды» жазуы сервер жазбаны қабылдағаннан кейін ғана шығады.

**Бір топ — бір ноутбук.** Топты бірінші ашқан құрылғы сол топқа бекітіледі, басқа құрылғы ол топқа кіре алмайды. Ноутбук ауысса немесе браузер тазаланса, мұғалім «Бақылау» бетінде **«Құрылғыны босату»** батырмасын басады. Сонда топ жаңа құрылғыдан қайта кіреді, деректер өшпейді.

**Енгізілмеген және 0 балл.** Белгі қойылмаған кезең «—» болып көрінеді. Топ **«Сақтау және келесі кезең»** батырмасын басқанда белгісіз қалған оқушыға 0 балл есептеледі.

**Интернет үзілсе:** өзгерістер құрылғыда кезекте тұрады (Firestore offline кэші). Байланыс қайта қосылғанда тек өзгерген өрістер жіберіледі, басқа топтың деректері өзгермейді. Бетті қайта ашқанда құрылғы сол сабаққа, сол топқа және сол кезеңге қайта оралады.

## 2. Дерекқор құрылымы (Cloud Firestore)

```
teachers/{uid}                                   ← мұғалім (консольде қолмен қосылады)
sessions/{КОД}                                   ← бір сабақ
    teacherUid, status: "open" | "ended", title, createdAt, endedAt
sessions/{КОД}/groups/{0..3}                     ← бір топ
    ownerUid            — топқа бекітілген құрылғы (анонимді аккаунт)
    names   {"0": "Айзат Серікова", ...}         — оқушылардың аты-жөні (7 орын)
    s3      {"0": "ok" | "bad", ...}             — топтық жұмыс, топтың өз белгісі
    s3Final {"0": "ok" | "bad", ...}             — мұғалімнің түзетуі
    done    {"s1": true, ...}                    — аяқталған кезеңдер
    lab     {temps: {"0": 20, ...}, ans: {"0": "...", ...}}
    updatedAt
sessions/{КОД}/groups/{g}/students/{0..6}        ← бір оқушы
    self  {s1: {"0": true}, s2: {...}, s4: {...}} — өзін-өзі бағалау
    final {s1: {"0": false}, ...}                — мұғалім түзеткен қорытынды
sessions/{КОД}/presence/{0..3}                   ← топ құрылғысының «тірі» белгісі
    lastSeen, online
```

Әр өзгеріс тек бір өрісті жазады, мысалы `names.3` немесе `self.s4.2`. Толық күй бір объект ретінде қайта жазылмайды. Сондықтан бір уақытта жазып жатқан төрт топ бір-бірінің деректерін өшірмейді.

`localStorage`-та тек осы құрылғының экран күйі (ашық бөлім, кезең, таңдалған оқушы) және қай сабаққа қосылғаны сақталады. Ол деректерді құрылғылар арасында тасымайды.

## 3. Қолжетімділік ережелері

Ережелер `firestore.rules` файлында. Оларды HTML емес, Firebase сервері тексереді:

* сабақ ашу, нәтижелерді көру және түзету — тек `teachers` жинағында тіркелген, email-мен кірген мұғалім (тек өз сабақтары);
* топ құрылғысы тек өзі бекітілген топтың құжатын оқиды және өзгертеді. Басқа топты оқуға да, жазуға да рұқсат жоқ;
* топ `s3Final`, `final`, `ownerUid` өрістеріне жаза алмайды. Демек мұғалімнің түзетуін өзгерте алмайды;
* сабақ аяқталғаннан кейін (`status: "ended"`) топтардың барлық жазбасы қабылданбайды;
* мәндер тексеріледі: аты-жөні ≤ 40 таңба, температура 0–110, жауап ≤ 2000 таңба, белгілер тек true/false немесе «ok»/«bad».

**Құпия кілттер HTML-де жоқ.** `firebase-config.js` ішіндегі `apiKey` құпия емес, ол тек жобаның атауы сияқты. Ешқандай admin кілті немесе мұғалімнің құпия сөзі файлдарда сақталмайды. Құпия сөз тек Firebase Authentication-да тұрады.

## 4. Іске қосу қадамдары

### 4.1. Firebase жобасын ашу
1. <https://console.firebase.google.com> сайтына Google аккаунтымен кіріңіз.
2. **Create a project** (Жоба құру) батырмасын басыңыз. Атауын жазыңыз, мысалы `fizika-qainau`. Google Analytics-ті өшіре беруге болады. Тегін **Spark** жоспары жеткілікті.

### 4.2. Кіру тәсілдерін қосу (Authentication)
1. Сол мәзірден **Build → Authentication → Get started** ашыңыз.
2. **Sign-in method** қойындысында:
   * **Email/Password** → *Enable* → **Save**;
   * **Anonymous** → *Enable* → **Save** (топ ноутбуктері үшін, тіркелусіз).
3. **Users** қойындысында **Add user** басыңыз. Мұғалімнің email-ін және құпия сөзін енгізіңіз (кемінде 6 таңба, күрделі болсын).
4. Жаңа жолдағы **User UID** мәнін көшіріп алыңыз (мысалы `kR3x…9QZ`).

### 4.3. Дерекқор ашу (Firestore)
1. **Build → Firestore Database → Create database**.
2. Location (орналасу) таңдаңыз, мысалы `europe-west3 (Frankfurt)` немесе `eur3`. Кейін өзгертуге болмайды.
3. **Start in production mode** таңдап, **Create** басыңыз.
4. **Rules** қойындысындағы мәтінді толық өшіріп, орнына осы репозиторийдегі `firestore.rules` файлының бүкіл мазмұнын қойыңыз. Содан кейін **Publish** басыңыз.
5. **Data** қойындысында **Start collection** басыңыз:
   * Collection ID: `teachers`
   * Document ID: 4.2-қадамда көшірген **User UID**
   * Field: `name`, Type: `string`, Value: `Маженова Салтанат Төлендіқызы` → **Save**.

   (Бірнеше мұғалім болса, әрқайсысына осындай құжат қосыңыз.)

### 4.4. Веб-қосымшаны тіркеу және баптауды көшіру
1. ⚙ **Project settings → General** бетінде, төмендегі **Your apps** бөлімінде **`</>`** (Web) белгішесін басыңыз.
2. Атау беріңіз, мысалы `qainau-web`. Firebase Hosting құсбелгісін қоюға болады. Содан кейін **Register app** басыңыз.
3. Көрсетілген `firebaseConfig` ішіндегі мәндерді `public/firebase-config.js` файлына қойыңыз:
   ```js
   window.FIREBASE_CONFIG = {
     apiKey: 'AIza…',
     authDomain: 'fizika-qainau.firebaseapp.com',
     projectId: 'fizika-qainau',
     storageBucket: 'fizika-qainau.firebasestorage.app',
     messagingSenderId: '1234567890',
     appId: '1:1234567890:web:abc…'
   };
   ```

### 4.5. Жариялау (сайтқа шығару)
Қосымша `file://` арқылы ашылмайды, оны сайт ретінде жариялау керек. Екі жолдың біреуін таңдаңыз.

**А. Firebase Hosting (ұсынылады, тегін, HTTPS):**
1. Компьютерге Node.js орнатыңыз: <https://nodejs.org> (LTS нұсқасы).
2. Терминалды осы `fizika-qainau-online` папкасында ашып, мыналарды орындаңыз:
   ```bash
   npm install -g firebase-tools
   firebase login
   firebase use --add          # 4.1-қадамдағы жобаны таңдаңыз, alias: default
   firebase deploy --only firestore:rules,hosting
   ```
3. Соңында `Hosting URL: https://fizika-qainau.web.app` сияқты сілтеме шығады. Қосымшаның мекенжайы осы.

**Ә. Бағдарлама орнатпай (Netlify Drop):**
1. <https://app.netlify.com/drop> бетін ашып, тіркеліңіз.
2. `public` папкасын (ішінде `index.html` және толтырылған `firebase-config.js` бар) бетке сүйреп тастаңыз.
3. Берілген `https://…netlify.app` сілтемесін Firebase-ке қосыңыз: **Authentication → Settings → Authorized domains → Add domain**.
4. Бұл жолда ережелер Hosting арқылы жарияланбайды. Сондықтан 4.3-қадамдағы **Rules → Publish** міндетті түрде орындалған болуы керек.

### 4.6. Сабақ алдындағы тексеру (5 құрылғы)
1. Мұғалімнің ноутбугінде сілтемені ашып, **МҰҒАЛІМ** арқылы кіріңіз де, **Жаңа сабақ отырысын ашу** батырмасын басыңыз.
2. Экрандағы QR кодты немесе сілтемені 4 ноутбукта ашыңыз. Әрқайсысында **ТОП** батырмасын басып, кодты енгізіп, 1–4-топтың біреуін таңдаңыз.
3. Мұғалім экранындағы «Топтардың қосылуы» бөлімінде төрт топ та **Қосылған** болуы керек.
4. Төрт ноутбукта бір уақытта аттарды жазып, белгі қойыңыз. Мұғалім кестесі бетті жаңартпай толуы керек.
5. Бір ноутбукта Wi-Fi-ды өшіріңіз. Сол ноутбукта **Байланыс жоқ**, мұғалімде **Байланыс үзілді** шығады. Wi-Fi қайта қосылғанда өзгерістер өзі жіберіледі.
6. Сабақ соңында **Сабақты аяқтау**, содан кейін **CSV жүктеу** немесе **Басып шығару / PDF** басыңыз.

## 5. Тесттер (әзірлеушіге)

Тесттер ресми Firebase эмуляторларында (Auth + Firestore) нақты `firestore.rules` ережелерімен жүреді. Java 11+ және Node 20+ керек.

```bash
npm install
npm run test:rules   # 9 тест: топтар оқшау, мұғалім түзетуі, сабақ аяқталғаннан кейін жазуға тыйым
npm run test:e2e     # 5 бөлек браузер: 1 мұғалім + 4 топ бір уақытта
```

`test:e2e` тексеретін нәрселер:
* 4 топ бір уақытта қосылады, бөгде 6-құрылғы бос емес топқа кіре алмайды;
* 22 оқушының аты, 1–4 кезең белгілері және зертхана мәндерін төрт топ қатар енгізеді;
* мұғалім кестесі бетті жаңартпай толады, әр оқушының баллы формуламен сәйкес келеді;
* 2-топтың «Графикті тазалау» батырмасы тек 2-топтың кестесін тазалайды;
* мұғалімнің түзетуі топ ноутбугінде құлыпталып көрінеді, топ оны өзгерте алмайды;
* 3-топтың интернеті өшеді: топта «Байланыс жоқ», мұғалімде «Байланыс үзілді». Сол кезде 4-топ жұмысын жалғастырады. Интернет қосылғанда 3-топтың өзгерісі жіберіледі;
* бетті қайта жүктегенде деректер мен ашық кезең қалпына келеді;
* мұғалім «Құрылғыны босату» батырмасын басады, CSV жүктеледі, сабақ аяқталғаннан кейін өзгертуге тыйым салынады.

## 6. Шектеулер
* Тегін Spark жоспарының лимиті: тәулігіне 50 000 оқу және 20 000 жазу. Бір сабаққа шамамен 1–2 мың жазу кетеді, бұл жеткілікті.
* «Байланыс үзілді» белгісі топ ноутбугі 20 секунд сайын жіберетін сигнал арқылы анықталады. Сондықтан бұл белгі 1–1,5 минут кешігуі мүмкін. Бетті жапқанда белгі бірден шығады.
* Сабақ кодын білетін кез келген адам бос топқа кіре алады. Сондықтан кодты тек сыныпта көрсетіңіз. Бөтен құрылғы кіріп кетсе, «Құрылғыны босату» батырмасын басыңыз.

## Ойын

- **Ойнау:** 7 тақырып (жануарлар, отбасы, мектеп, тағамдар, түстер, сандар, табиғат), әр тақырыпта 10 сөз. Бота 🐪 лабиринттен сөздің әріптерін ретімен жинайды. Лабиринтте «қақпан әріптер» бар (**қ** орнына «к», **ұ** орнына «у»).
- **Сөздік:** 70 сөз суретімен және орысша аудармасымен.
- **Тест:** 12 сұрақ. «Бастапқы тест» ойынға дейін, «Қорытынды тест» 1–2 аптадан кейін тапсырылады.
- **Нәтижелер:** тест балдарын салыстыру, қай әріпте қате көп екені, CSV файлына сақтау. Деректер тек сол құрылғыда сақталады, баланың аты емес, тек коды жазылады.

## Не толтыру керек

Құжаттардағы **сары түспен** белгіленген орындарды оқушы толтырады:

1. Сауалнама өткізіп, 3-кестені толтыру (ата-ана келісімі: жұмыстың Г қосымшасы).
2. Бастапқы тест → 1–2 апта ойын → қорытынды тест. Нәтижелерді ойынның «Нәтижелер» бөлімінен 7-, 8-кестелерге, аннотацияға, 8-слайдқа және стендке көшіру.
3. Күнделіктің күндерін және нәтижелерін жазу.
4. Мәтінді нақты сервисте антиплагиатқа тексеріп, анықтамадағы сервисті, пайызды және күнді жазу. Тексеру есебін PDF түрінде қоса беру.
5. Титулдағы аты-жөнді тек ұйымдастырушыға берілетін данаға жазу. Қазылар алқасының данасында тек шифр қалады (4.8).
6. «Сөздер лабиринті» ойынының сілтемесі дайын болғанда стендтегі QR-кодты жасау: `STAND_URL=https://... bash src/build.sh`.

## Академиялық адалдық туралы маңызды ескерту

Ережелердің 4.10-тармағы ЖИ-ге **жұмыстың дайын мәтінін, деректерін, талдауын және қорытындысын** жасатуға тыйым салады. Ал 2.16-тармақ бойынша толық ЖИ жасаған жұмысқа акт жасалады. Сондықтан:

- Бұл жұмыстың мәтіні Claude Code көмегімен **жоба-үлгі** ретінде дайындалды. Оқушы оны жетекшісімен бірге оқып, **өз сөзімен қайта жазуы** керек. Әсіресе кіріспе, қорытынды және рефлексия оқушының өз ойы болуы тиіс.
- Зерттеу деректері (сауалнама, тест) **тек нақты** жиналады. Құжаттарда ойдан шығарылған сан жоқ, барлық нәтиже орны бос қалдырылды.
- Декларацияда ЖИ-дің нақты не істегені шынайы көрсетіледі. Сары жолдарды шын мәнінде не болғанына қарай түзетіңіз.
- 2-дереккөздің (үлгілік оқу бағдарламасы) нақты бұйрық нөмірі мен редакциясын мұғаліммен нақтылаңыз.

## Қайта жинау

```bash
cd sozder-labirinti/src && npm install   # docx, pptxgenjs, qrcode
bash build.sh
```

LibreOffice, Node.js, Python (`pypdfium2`) және Playwright Chromium қажет. PDF файлдары Times New Roman-ның метрикалық аналогы Liberation Serif қаріпімен жасалған. Соңғы PDF-ті Word-тан қайта сақтаған дұрыс.

# «Буктюб пен буктокерлер: әлеуметтік желі жастардың кітап оқуына әсер ете ме?» – «Зерде» зерттеу жобасы

Секция: Қазақ тілі және әдебиеті (ҚГБ), «Орта буын», 8-сынып, жеке жоба.

## Файлдар

| Файл | Не үшін |
|---|---|
| `Zertteu_zhumysy.docx / .pdf` | Зерттеу жұмысы (ұйымдастырушыға арналған дана) |
| `Zertteu_zhumysy_qazylar_danasy.docx / .pdf` | Қазылар данасы – аты-жөнсіз, тек шифр |
| `Zertteu_kestesi.xlsx` | Оқушы толтыратын кесте: сауалнама, қазақ тіліндегі кітап блогерлері, сұхбат |
| `Google_Forms_saualnama.gs` | Сауалнаманы Google Forms-та өздігінен жасайтын скрипт |
| `Zertteu_kundeligi.docx` | Зерттеу күнделігі (6-қосымша) |
| `ZhI_deklaratsiyasy.docx` | ЖИ пайдалану туралы декларация (4-қосымша) |
| `Etika_paragy.docx` | Этика және қауіпсіздік бақылау парағы (5-қосымша) |
| `Zhetekshi_pikiri.docx` | Жетекші пікірі |

## Деректер туралы

Бастапқы жоба құжатындағы сауалнама (120 оқушы) және сұхбат сандары үлгі ретінде берілген, сондықтан жұмысқа енгізілмеді. Буктрейлер тәжірибесі жобадан алынып тасталды: зерттеу сауалнама, қазақ тіліндегі кітап блогерлерін талдау және сұхбат арқылы жүргізіледі. Нәтижелер бөлімдері, 3-кесте, 2–3-суреттер, аннотация, қорытынды, болжамды тексеру, күнделік пен жетекші пікірі `Zertteu_kestesi.xlsx` толтырылғанда нақты деректерден өздігінен жазылады.

Теориялық бөлімдегі статистика бастапқы дереккөздер бойынша тексерілді (TikTok Newsroom 19.03.2026, Forbes, InsideHook/Circana, Russian Life). Расталмаған «75 млн бейне» дерегі алынып тасталды.

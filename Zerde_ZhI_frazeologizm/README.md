# «ЖИ қазақтың тұрақты тіркестерін қалай түсіндіреді?» – «Зерде» зерттеу жобасы

Секция: Қазақ тілі және әдебиеті (ҚГБ), «Орта буын» (5–8 сынып), жеке жоба.

## Файлдар

| Файл | Не үшін |
|---|---|
| `Zertteu_zhumysy.docx / .pdf` | Зерттеу жұмысы (ұйымдастырушыға арналған дана, титулда аты-жөн бар) |
| `Zertteu_zhumysy_qazylar_danasy.docx / .pdf` | Қазылар данасы – аты-жөнсіз, тек шифр (Ереже 4.8) |
| `Tazhiribe_kestesi.xlsx` | Тәжірибе деректерін жазатын кесте: сары ұяшықтарды толтырасыз, қорытынды өздігінен есептеледі |
| `Zertteu_kundeligi.docx` | Зерттеу күнделігі (6-қосымша) |
| `ZhI_deklaratsiyasy.docx` | ЖИ пайдалану туралы декларация (4-қосымша) |
| `Etika_paragy.docx` | Этика және қауіпсіздік бақылау парағы (5-қосымша) |
| `Zhetekshi_pikiri.docx` | Жетекші пікірінің үлгісі |

## Оқушы не істеуі керек

1. **Тәжірибені өзі жүргізеді.** Үш ЖИ құралын таңдап, `Tazhiribe_kestesi.xlsx` файлындағы нұсқау бойынша 30 тіркесті, 6 синоним/антоним тапсырмасын және 5 мағыналық топты сұрайды, жауаптарды сөздікпен салыстырып балл қояды. Нәтижелерді ойдан жазуға болмайды (Ереже 2.16, 4.10).
2. **Сары белгіленген орындарды толтырады** (`[___]`, `[…]`). «НҰСҚАУ» деп басталатын сары абзацтарды тапсыру алдында өшіреді.
3. **Мәтінді өз сөзімен қайта жазады.** Ереже 4.10 бойынша ЖИ жасаған дайын мәтінді ұсынуға болмайды: бұл нобайды жоспар ретінде пайдаланып, әр бөлімді түсініп, өз сөзіңізбен жазыңыз. Рефлексияны тек өзіңіз жазасыз.
4. **Декларацияны шындыққа сәйкес толтырады.** Көмекші ретінде пайдаланылған ЖИ-ді де көрсетесіз.
5. Сөздік тізбесіндегі мағыналарды және дереккөздер тізімін кітапханадан тексереді.

## Қайта құрастыру (толтырылған Excel-мен)

Кестені толтырғаннан кейін жұмыстағы 7–11-кестелер, 4–5-суреттер, аннотация мен қорытындыдағы сандар өздігінен толады:

```sh
cd source
npm install          # бір рет
pip install openpyxl matplotlib pymupdf
./build.sh           # LibreOffice қажет
```

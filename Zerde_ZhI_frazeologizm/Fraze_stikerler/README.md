# Фразеостикерлер

«ЖИ қазақтың тұрақты тіркестерін қалай түсіндіреді?» жобасының сөздігінен алынған 12 тұрақты тіркес. Тіркестер чатта айтуға ыңғайлы түрге келтірілді, ал астындағы түсінік сөздіктегі мағынасына сүйенеді.

| № | Стикер | Сөздіктегі тіркес мен мағынасы |
|---|---|---|
| 01 | Асығың алшысынан түссін! | Асығы алшысынан түсті – жолы болды |
| 02 | Екі езуім екі құлағымда! | Екі езуі екі құлағына жету – қуану |
| 03 | Арамыздан қыл өтпейді | Арасынан қыл өтпейді – өте тату |
| 04 | Қас пен көздің арасында! | Қас пен көздің арасында – тез |

| 06 | Бармағымды тістедім… | Бармағын тістеді – өкінді |
| 07 | Ит өлген жер екен! | Ит өлген жер – алыс, қашық |
| 08 | Құлағымды түрдім | Құлағын түру – назар салу |

## Файлдар

- `01.webp … 12.webp`, `tray.png` – WhatsApp стикер талабына сай: 512×512, мөлдір фон, әрқайсысы 100 КБ-тан аз; белгіше 96×96. Бәрі `Fraze_stikerler_WhatsApp.zip` ішінде.
- `01.png … 12.png` – сурет ретінде жіберуге немесе iPhone-да стикер жасауға (`Fraze_stikerler_PNG.zip`).
- `Barlygy.png` – барлық стикер бір суретте.

## WhatsApp-қа қосу

- **Android:** Play Market-тен стикер жинағын жасайтын қосымшаны (мысалы, «Sticker Maker») орнатып, жаңа жинақ ашыңыз, 12 файлды қосып, «WhatsApp-қа қосу» батырмасын басыңыз.
- **iPhone:** WhatsApp-та чатты ашып, стикер белгішесі → «Жасау» (Create) арқылы PNG суретті таңдаңыз; немесе App Store-дағы стикер қосымшасын пайдаланыңыз.
- **Ең оңай жолы:** PNG файлды чатқа кәдімгі сурет ретінде жіберу.

Қайта жасау: `cd source && python3 stikerler.py ../Fraze_stikerler`

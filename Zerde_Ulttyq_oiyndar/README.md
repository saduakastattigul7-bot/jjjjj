# «Ертегілер мен жырлардағы ұлттық ойындар» – «Зерде» зерттеу жобасы

Секция: Қазақ тілі және әдебиеті (ҚГБ), «Орта буын» (5–8 сынып), жеке жоба.

## Файлдар

| Файл | Не үшін |
|---|---|
| `Zertteu_zhumysy.docx / .pdf` | Зерттеу жұмысы (ұйымдастырушыға арналған дана) |
| `Zertteu_zhumysy_qazylar_danasy.docx / .pdf` | Қазылар данасы – аты-жөнсіз, тек шифр |
| `Zertteu_kestesi.xlsx` | Оқушы толтыратын кесте: шығармалар, мәтін талдауы, сауалнама; «Қорытынды» өздігінен есептеледі |
| `Zertteu_kundeligi.docx` | Зерттеу күнделігі (6-қосымша) |
| `ZhI_deklaratsiyasy.docx` | ЖИ пайдалану туралы декларация (4-қосымша) |
| `Etika_paragy.docx` | Этика және қауіпсіздік бақылау парағы (5-қосымша) |
| `Qorgau_prezentatsiyasy.pptx` | Қорғауға арналған презентация (15 слайд, әр слайдта баяндама мәтіні мен соңында ықтимал сұрақтар) |
| `Zhetekshi_pikiri.docx` | Жетекші пікірі |

Сауалнама парағы мен ата-ана келісім парағы – жұмыстың Ә және Б қосымшаларында (басып шығаруға дайын).

## Google Forms сауалнамасы

`Google_Forms_saualnama.gs` – сауалнаманы Google Forms-та өздігінен жасайтын скрипт:

1. https://script.google.com → «Жаңа жоба», файлдың мәтінін қойып сақтаңыз.
2. `createSurvey` функциясын іске қосыңыз (Run), рұқсат беріңіз. Журналда сауалнама сілтемесі, өңдеу сілтемесі және жауаптар кестесі шығады.
3. Сауалнама біткен соң `kestegeAudaru` функциясын іске қосыңыз: жауаптар кестесінде «Кестеге» парағы пайда болады. Оны A2 ұяшығынан бастап көшіріп, `Zertteu_kestesi.xlsx` → «Сауалнама» парағының A2 ұяшығына қойыңыз.

Немесе жауаптар кестесін Файл → Жүктеп алу → Microsoft Excel (.xlsx) арқылы жүктеп, `source/saualnama_zhauaptary.xlsx` деп сақтаңыз да, зерттеу кестесін қайта жасаңыз (келісім бермегендердің жауабы өздігінен алынып тасталады):

```sh
cd source && python3 make_xlsx.py ../Zertteu_kestesi.xlsx oqushy_bastapqy.xlsx saualnama_zhauaptary.xlsx
```

Мектептің Google Workspace аккаунтымен жасасаңыз, форма параметрлерінде «Тек ұйым пайдаланушылары» шектеуін өшіріңіз, әйтпесе оқушылар кіре алмауы мүмкін.

## Оқушы не істейді

1. 11 шығарманы оқып, ойын кездесетін әр эпизодты `Zertteu_kestesi.xlsx` → «Мәтін талдауы» парағына жазады (шығарма, ойын, эпизод, қызмет коды, үзінді, беті).
2. Ата-ана келісімін жинап, сыныптастар арасында сауалнама жүргізеді, жауаптарды «Сауалнама» парағына кодпен енгізеді.
3. Толтырылған кестені жібереді – нәтижелер, диаграммалар, карточкалар, аннотация мен қорытынды өздігінен толады, содан кейін талдау мәтіні нақты деректерге сай жазылады.

## Қайта құрастыру

```sh
cd source && npm install && ./build.sh
```

## Енгізілген деректер

- `source/oqushy_bastapqy.xlsx` – оқушының мәтін талдауы және шығармалар басылымдары (өзгеріссіз). Басылымдар 3-кестеде қысқаша, дереккөздер тізімінде толық (13–23) берілген.
- `source/saualnama_zhauaptary.xlsx` – Google Forms жауаптары: 22 жауап, оның 3-еуі ата-ана келісімі жоқ болғандықтан алынбады, 19 қатысушы (5-сынып 2, 6-сынып 8, 7-сынып 5, 8-сынып 4).
- `source/tuzetuler.json` – «Эпизод» пен «Кейіпкер» бағандарының дәйексөз бойынша толықтырулары.

Презентацияны қайта жасау: `cd source/deck && npm install && PPTX_SKILL=<pptx skill> node deck.js ../../Qorgau_prezentatsiyasy.pptx`
